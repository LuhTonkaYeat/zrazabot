# 🍽 Zraza Bot

*Личный* (не принимаю критику относительно слегка пошлых функциональностей) tg-бот для чата с кентами. Считает съеденные зразы (локальный рофл), добавляет азартные механики, систему перков и экономику.

## Команды

| Команда | Описание |
|---------|----------|
| `/zraza` | Съесть порцию зраз (1–20 шт). Кулдаун 30 мин. <br>✨ 5% шанс на +67 зраз (Чудо)<br>💩 10% шанс обнуления (спасает перк *Antigovno*) |
| `/stat` | Топ-5 по текущему количеству зраз |
| `/top` | Полная статистика: абсолютные лидеры, топ говноедов, лакеров, воров и донатеров |
| `/steal` | Ответом на сообщение — украсть 1–5 зраз (шанс 50%, кулдаун 5ч) |
| `/give [N]` | Ответом на сообщение — подарить N зраз другу |
| `/slot [N]` | Слот-машина (ставка ≤50). <br>💎💎💎 = x10, 7️⃣7️⃣7️⃣ = x7, пара = x1.5. Кулдаун 5 мин |
| `/all` | All-in! Ставишь всё. Кулдаун 3 часа |
| `/shop` | Магазин перков: ежедневные бонусы, скидки на кулдауны и защита от обнуления |
| `/kisel` | Секретная команда |

## Фишки перков

- 🛒 **Система перков:** Покупай улучшения за зразы (*Base, Plus, Prime* для ежедневных наград, *BMW* для снижения кулдаунов, *Antigovno* для защиты счета).
- 💬 **Balabol / Gigabalabol:** Получай пассивный доход за активность в чате (награда за каждые 50 сообщений).
- 💰 **Jew Perk:** Пассивный налог 3% с проигрышей других игроков в казино.
- 📊 **Живой баланс:** В слотах и алл-ине сразу виден итоговый баланс после ставки.
- ⚡ **Оптимизация:** Глобальное подключение к SQLite для мгновенной работы даже при высокой нагрузке.

## Технологии

- Go 1.26.3
- SQLite (modernc.org/sqlite)
- gopkg.in/telebot.v3

## Деплой

Бот работает на [BotHost](https://bothost.ru) в Docker контейнере с постоянным хранилищем `/app/data`.

## Переменные окружения

- `BOT_TOKEN` — токен бота от @BotFather

## Особенности экономики

- ⏰ **Кулдауны:** 30 мин на еду, 3 мин на слоты, 5 часов на кражу, 3 часа на All-in.
- 🎰 **Шансы в слотах:** ~52% на любой выигрыш. Прозрачная математика без скрытых рандомов.
- 🛡️ **Защита:** Перк *Antigovno* снижает шанс обнуления до 2%.
- 🚗 **Скорость:** Перк *BMW M4* уменьшает все кулдауны на 25%.
