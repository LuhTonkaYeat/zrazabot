# 🍽 Zraza Bot

Личный tg-бот для чата с кентами. Считает съеденные зразы (локальный рофл), добавляет случайные гарниры, слоты, кражи и подарки.

## Команды

| Команда | Описание |
|---------|----------|
| `/zraza` | Съесть порцию зраз (от 1 до 10). Случайный гарнир. 5% чудо +67, 10% обнуление с 💩 |
| `/stat` | Топ-5 по текущему количеству зраз |
| `/top` | Абсолютные лидеры + топы говноедов, лакеров, воров, донатеров |
| `/steal` | Ответом на сообщение — украсть 1-5 зраз (шанс 50%, кулдаун 5ч) |
| `/give [N]` | Ответом на сообщение — подарить N зраз |
| `/slot [N]` | Слоты (ставка ≤33). 💎💎💎 = x10, бонус-раунд при 💎. Кулдаун 10 сек |
| `/kisel` | Секретная команда |

## Технологии

- Go 1.23
- SQLite
- gopkg.in/telebot.v3
- modernc.org/sqlite

## Деплой

Бот работает на [BotHost](https://bothost.ru) в Docker контейнере с постоянным хранилищем `/app/data`.

## Переменные окружения

- `BOT_TOKEN` — токен бота от @BotFather

## Особенности

- ⏰ Кулдаун 1 час на `/zraza`, 5 часов на кражу, 10 секунд на слоты
- 🍝 4 вида гарниров
- 💩 10% шанс обнулиться с говном
- 🎰 Слот-машина с джекпотом и бонус-раундом
- 🦝 Кражи и 🎁 подарки между пользователями
- 📊 Полная статистика и рейтинги
- 🥣 Правильные склонения "зраз" в разных падежах
